# Описание HON-platform

HON-platform (Human Open Network Platform) - социальная сеть с открытым исходным кодом, предназначенная для запуска на собственном сервере.

Приложение реализовано на следующем стеке:

| Платформа | Технология |
| :--- | :--- |
| Сервер | Nest.js |
| Клиент | Next.js |
| Мобильное приложение | React Native |
